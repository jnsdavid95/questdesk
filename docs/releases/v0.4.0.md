# QuestDesk v0.4.0 — primeira versão pública

Criado por **Jonas David Kosniyzeko**.

Versão experimental com tarefas Kanban, EXP, Gold, inventário, temas de fantasia, calendário e criação de personagens LPC.

## Destaques

- Missões com recompensas únicas e progressão de níveis.
- Personagem modular com 20 peças e drops por conclusão de tarefas.
- Agenda com agendamento, arquivos ICS e leitura de calendários públicos Google.
- Três temas editáveis e salvamento local.

## Distribuições preparadas

- `QuestDesk-Setup-0.4.0-windows-x64.exe` — instalador por usuário, menu Iniciar e desinstalação.
- `QuestDesk-0.4.0-linux-x86_64.AppImage` — aplicativo portátil para Linux, incluindo Bazzite.

Os dois pacotes incluem o runtime Electron. Não é preciso Node.js para usá-los. Esta nota é um texto preparado para a Release; sua presença no código não indica que a Release já foi publicada.

## Validação

18 testes de domínio aprovados e build concluído. Interface revisada no Chromium; pacote NSIS passou no teste de integridade e AppImage teve conteúdo inspecionado. Instalação, execução e atualização nos sistemas de destino ainda precisam de teste. O Windows não tem assinatura digital e a versão não possui atualizador automático.
